# OdinEye — Admin Dashboard Walkthrough (Narration Script)

**For:** you to read aloud while screen-recording the admin demo.
**Target length:** **2.5 minutes** (safely inside 2–3 min). ~360 spoken words. Read at a calm, natural pace — don't rush.
**Voice:** calm, confident, conversational — like showing a friend around. Use contractions and short sentences.
**How to read this:** plain lines are what you **SAY**. Lines in _[brackets]_ are **on-screen actions** — do them, don't read them.

---

## Scene 1 — Opening (≈12s)

_[Start on the Admin Overview page.]_

"Hi — I'll walk you through OdinEye as an admin. The admin sets everything up: creating projects, bringing the team in with the right roles, and connecting the tools we already use — GitHub, Jira, and Slack. Let me show you, starting from scratch."

---

## Scene 2 — Creating a project (≈25s)

_[Click **Projects** → **+ Create Project**.]_

"First, every admin creates a project — that's one product or codebase we want to track.

_[Type a name, e.g. "Payments Service". Add a Jira key if the field shows, e.g. "PAY".]_

I'll name it, and add the Jira project key so OdinEye knows which Jira board belongs to it.

_[Click Create.]_

Done — it's in my list now, with its GitHub link, members, and created date."

---

## Scene 3 — Admin Overview (≈18s)

_[Click **Overview**.]_

"This is the Admin Overview — my control panel. From here I reach everything I manage: projects, members, integrations, and settings.

_[Hover the cards.]_

It also flags what needs attention — like a project with no GitHub repo connected yet — so nothing slips through."

---

## Scene 4 — Projects list (≈18s)

_[Click **Projects**. Hover the columns, then the Delete action without clicking.]_

"In Projects I see every project at a glance — its repo, its members, when it was created. I can delete one from here too; it asks me to confirm first, since that's permanent.

_[Click a project to open it.]_

Let me open one."

---

## Scene 5 — Inside a project (≈38s)

_[On the project detail page.]_

"Each project has three parts.

_[Point to the info section.]_

The details — name, Jira key, and created date.

_[Scroll to the GitHub section.]_

The GitHub connection — I link the project to a real repository with one-click GitHub App authorization. No personal tokens. Once linked, OdinEye pulls in the history and starts tracking pull requests and deployments automatically.

_[Scroll to Members. Point to a role dropdown.]_

And the members — who works here and what they can do. In OdinEye, roles are per project: the same person can be a Manager on one project and a Developer on another. I set their role here, and I can remove them in one click."

---

## Scene 6 — Members & approvals (≈22s)

_[Click **Members**.]_

"The Members page is the whole workspace in one view — each person's details, their system role, and the projects they're on.

_[Scroll to pending join requests; hover Approve / Reject.]_

And when someone asks to join the company, their request lands here — I approve or reject it. So nobody gets in without me."

---

## Scene 7 — Integrations (≈28s)

_[Click **Integrations**. Point to each card.]_

"Integrations connect OdinEye to the tools we already use. GitHub — one-click App authorization, linking repos, and syncing historical data. Jira — pulling in issues to track the team's workload. And Slack — so alerts reach the channel the team actually watches.

_[If a 'send test event' button exists, click it.]_

I can even fire a test event to confirm Slack is wired up."

---

## Scene 8 — Settings & close (≈20s)

_[Click **Settings**. Scroll near Delete Organisation but don't click. Then return to Overview.]_

"And Settings holds the company configuration — plus the most sensitive controls, like deleting the organisation, kept behind a confirmation.

So that's the admin side: create projects, connect GitHub, Jira, and Slack, bring the team in, and set everyone's role. Once that's done, the developers and managers get their dashboards — which I'll show next."

---

### Every admin function covered
Create project (name + Jira key) · Delete project (confirm) · Admin Overview + status flags · Projects list · Project info · GitHub connection (App auth, repo link, historical sync) · Per-project roles (Manager/Developer) + remove member · Members page (system roles, assigned projects) · Approve/reject join requests · Integrations: GitHub, Jira, Slack (+ test event) · Settings + delete organisation

**Timing:** scene estimates sum to ~2m30s. If you land under 2 minutes, slow down and pause between scenes; if over 3, cut Scene 4 to one sentence.
