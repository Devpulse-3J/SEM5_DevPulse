Configuration export placement and renaming guide
=================================================

This archive retains the repository-relative paths. Extract it at the root of
the project and preserve every filename unless a rename below is explicitly
called for. Do not commit files containing real credentials.

Template activation: when you need a missing active local configuration, copy
the matching *.example file in the same directory and remove only the
`.example` suffix (for example, `.env.local.example` -> `.env.local`). Fill in
the required values after copying. Existing active files in this archive should
keep their current names. Files marked “archive only” are backups and should
not replace an active file unless deliberately restoring that backup.
